# Stack
- Bun and Bun tests
- NextJS
- TypeScript
- Biome
- Playwright

# Rules
- TypeScript strict mode
- No implicit boolean conversions
- No type coercion
- Avoid type casting, ie. `String()`, `Number()`
- No single line if statements
- Use discriminated unions for type narrowing
- Place helper functions after main functions
- Use early returns to reduce nesting
- Prefer ternary expression in TSX/JSX over guard and default operators
- Prefer arrow functions
- Modern TypeScript, ie. `Array.toSorted()`
- No non-null assertions
- Prefer `const` over `let`
- Never use `var`
- Prefer `for...of` over `forEach`
- Do not inline complex types or variables
